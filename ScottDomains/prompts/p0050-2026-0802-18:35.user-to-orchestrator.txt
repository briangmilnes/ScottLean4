Yes — **`\N`** then **Space** (or Tab) → **ℕ**.

So in the editor you type: backslash, capital N, space. The `\N` will briefly show, then flip to ℕ the moment you hit Space.

- You're in a **`.lean` file in a Lean-enabled window** (it won't work in a plain text file or the terminal) — you are, so you're fine.
- Make sure it's **capital `N`** (`\n` lowercase isn't the natural numbers).
