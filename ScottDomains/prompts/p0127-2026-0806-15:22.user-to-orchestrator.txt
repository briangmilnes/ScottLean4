## What Theorem 3 needs before it can be attempted

It is not a proof problem first, it is a formalization decision. The paper:

> A fixed point operator `F` is a **class** of continuous functions `F_D : (D → D) → D` such that, for each cpo `D` and continuous `f : D → D`, `F_D(f) = f(F_D(f))`.

An operator indexed by *all* cpos is not a function in Lean — it is a family over a universe of types. Stating it needs a structure carrying a field for every `CompletePartialOrder` type in a universe, with uniformity quantifying over pairs of them joined by a strict continuous map. That choice determines whether the theorem is provable as stated or only in a restricted form, so it is the first thing r0018 must settle rather than something to discover mid-proof.
