**The topology carries the catalogue's point.** Openness is three conditions, not one: up-closed among finite points, up-closed to ∞, and `U ∞ → ∃ a, U a`. That third conjunct is inaccessibility, and it is exactly what excludes {∞} — an up-set that is not open. `vert_top_not_isOpen` proves it, axiom-free. That is the topological form of ∞ ∉ K(ℕ^∞), and why the base has one member per finite point and none for ∞.

**Both remaining fields change character on an infinite carrier:**

- **D2** — a closed set is now an arbitrary bounded set of naturals, so the generic point cannot be produced by case analysis. It is the **maximum**, constructed by induction on the bound (`vert_max_of_bounded`). The other branch, a closed set containing ∞, is forced to be everything.
- **D3 `basisCpt`** — first real content. The open covering ∞ contains an entire tail, leaving finitely many points below it. Assembling a subcover for those is done **one open at a time** (`vert_finite_cover`), because turning `∀ m, ∃ i, U i m` into a function `m ↦ i` is countable choice, which this development does not admit — `lem` is the only classical principle in scope. The induction is legitimate precisely because the goal is a `Prop`, so each existential is eliminated inside the proof rather than escaping as data.
