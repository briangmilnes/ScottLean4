Good thing to nail down early — you'll want a repeatable pipeline. There are three routes on this box; they differ mainly in *who renders the plot* and *whether the fonts match your document*.

## The three routes

| Route | How it works | Fonts match doc? | Best when |
|---|---|---|---|
| **pgfplots / TikZ** (native LaTeX) | LaTeX itself draws the plot from your function/data | ✅ yes (same TeX engine) | Publication-quality figures, everything version-controlled as text |
| **matplotlib** (Python) | Python renders → export PDF *or* PGF, then `\includegraphics` / `\input` | ⚠️ PDF: no; PGF backend: yes | Data-heavy plots, quick iteration, numeric work |
| **Wolfram/Mathematica** | `Plot[…]` → `Export[…, ".pdf"]`, then `\includegraphics` | ❌ no (unless you match fonts) | Matches Dana's existing `.nb` notebooks |

My recommendation for a math-tutoring/paper context: **pgfplots as the default** (text-based, reproducible, fonts match), reaching for matplotlib when you have real datasets. All of pgfplots ships with MacTeX (installing now) — nothing extra to install.

## Route 1 — pgfplots (native, recommended)

```latex
\documentclass{article}
\usepackage{pgfplots}
\pgfplotsset{compat=1.18}
\begin{document}
\begin{tikzpicture}
  \begin{axis}[axis lines=middle, xlabel=$x$, ylabel=$y$,
               domain=-3:3, samples=200, grid=both, legend pos=north west]
    \addplot[blue, thick]  {exp(-x^2)};        \addlegendentry{$e^{-x^2}$}
    \addplot[red, dashed] {sin(deg(x))/x};      \addlegendentry{$\operatorname{sinc} x$}
  \end{axis}
\end{tikzpicture}
\end{document}
```

`\addplot { <expr> }` plots a function symbolically; `\addplot table {data.dat}` plots data. Note the trig gotcha: pgfplots' `sin` takes **degrees**, so wrap with `deg(x)` for radians. For heavier expressions you can offload sampling to gnuplot with `\addplot gnuplot {…}`.

## Route 2 — matplotlib → LaTeX

Two sub-options. For matching fonts, use the **PGF backend** (outputs LaTeX drawing commands):

```python
import matplotlib; matplotlib.use("pgf")
import numpy as np, matplotlib.pyplot as plt
x = np.linspace(-3, 3, 400)
plt.plot(x, np.exp(-x**2))
plt.savefig("gauss.pgf")     # then \input{gauss.pgf}  (or savefig("gauss.pdf") + \includegraphics)
```

```latex
\usepackage{pgf}
...
\input{gauss.pgf}
```
