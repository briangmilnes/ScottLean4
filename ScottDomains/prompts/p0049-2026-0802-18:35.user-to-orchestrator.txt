how do I type N for the natural numbers?

## turn — assistant 2026-08-02T18:35:38.034000-07:00

In the Lean 4 VS Code editor you type Unicode with **backslash abbreviations**. For ℕ:

**Type `\N` then press Space (or Tab)** → it converts to **ℕ**.

(Alternatives that also work: `\nat` or `\bbN` — "blackboard-bold N".)

How the mechanism works:
- Type **`\`** to start an abbreviation, then the name; a little suggestion popup appears. **Space, Tab, or Enter commits** it to the symbol. (If you type `\N` and then a letter that would form a different abbreviation, keep going or hit Space to force the conversion.)
- The same pattern gives you the other number types you'll use constantly:

| Symbol | Type |
|---|---|
| ℕ | `\N` |
| ℤ | `\Z` |
| ℚ | `\Q` |
| ℝ | `\R` |
| ℂ | `\C` |
| → | `\to` or `\r` |
| ∀ | `\forall` or `\all` |
| ∃ | `\exists` or `\ex` |
| ≤ | `\le` |
| ∧ / ∨ | `\and` / `\or` |
| ⊢ | `\vdash` |

Handy trick: **hover over any symbol** already in a file and VS Code shows you the abbreviation to type it. So in your `Scratch.lean`, you could write `example (n : ℕ) : n + 0 = n := by simp` — type `ℕ` as `\N␣`.
