**The obstruction I reported as a wedge is gone.** The fix was the redesign I sketched, and it works:

Keep one **flat, unindexed** token type `DTok`, and carry the level in the *order* rather than the type:

```
leAt : Nat → DTok → DTok → Prop
```

level 0 is 𝕊's order; level n+1 is §5.1's entailment between step-function sets, phrased over `leAt n`. Comparing any two tokens at any level is now a `Prop` about two ordinary terms — **no indices, no casts**, which is exactly what defeated the indexed tower.

The second half of the trick is `stepOf`, reading *any* token as a finite set of step functions — ⊥ as the empty set (λy.⊥), ⊤ through one embedding (λy.⊤). One recursion then handles all levels uniformly instead of case-splitting on which token is "lower".

Proved on it, each `[propext]` and nothing more:

| theorem | content |
| --- | --- |
| `leAt_refl`, `leAt_trans` | `leAt n` is a preorder at every level |
| `leAt_bot_le` | ⊥ is below everything at every level |
| **`leAt_embTok`** | **e is an order-embedding**: `leAt (n+1) (embTok x) (embTok y) ↔ leAt n x y` |

`leAt_embTok` is the one that matters — the coherence the colimit runs on, and precisely the statement the indexed encoding could not express without transport.

**D∞ itself is not finished.** What remains is `depth`, iterated embedding, the stability lemma (comparing at any level above both depths gives the same answer — `leAt_embTok` by induction), then `bounded_lub` and a `treesUpTo`-style enumeration. That is ordinary `Prop`-level work now, roughly the size of §5.4, with no known obstacle — but it is not done, and §5.5's row stays open in §8 until it is.

One caution worth flagging on my earlier reasoning: I briefly thought the colimit order could be `∃ n, leAt n (eⁿ x) (eⁿ y)`, which `leAt_embTok` would make independent of n — and therefore equal to `leAt 0`, collapsing D∞ to 𝕊. That is wrong because eⁿ does not put a depth-d token "at level n"; the comparison has to happen at `max (depth x) (depth y)`. Worth recording so the next pass does not repeat it.
