# papers

Type-theory and foundations papers underpinning the Lean 4 work.

- **`Elaboration-in-Dependent-Type-Theory-deMoura-Avigad-Kong-Roux.pdf`** —
  *Elaboration in Dependent Type Theory*, Leonardo de Moura, Jeremy Avigad,
  Soonho Kong, Cody Roux. Describes the **elaboration algorithm behind Lean** —
  how surface syntax (implicit arguments, coercions, overloading, higher-order
  unification) is turned into fully explicit terms of dependent type theory.
  (Source: Avigad's CMU page, served as `constr.pdf`.)

- **`CalculusOfConstructionsCoquandHuet.pdf`** — *The Calculus of Constructions*,
  Thierry Coquand & Gérard Huet. The core dependent type theory (CoC) at the root
  of Lean's and Coq/Rocq's foundations.
